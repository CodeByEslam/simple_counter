# Counter App

A simple and interactive Counter application built using HTML, CSS, Bootstrap, and JavaScript.

## 📌 About The Project

This project is a simple counter application that allows the user to increase or decrease a number using two buttons.

The project was created to practice JavaScript basics, DOM manipulation, and using Bootstrap for styling.

## 🚀 Features

- Increase the counter value
- Decrease the counter value
- Simple and clean user interface
- Responsive design using Bootstrap
- Interactive buttons using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
